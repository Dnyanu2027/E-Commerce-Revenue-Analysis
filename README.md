
# 🛒 E-Commerce Revenue Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data using SQL to understand revenue performance, customer purchasing behavior, and product sales trends. SQL queries are used to extract, transform, and analyze data to generate meaningful business insights.

## 🎯 Project Objectives
- Analyze total revenue and sales performance.
- Identify top-performing products and categories.
- Understand customer purchasing patterns.
- Analyze order trends and sales performance.
- Answer business questions using SQL queries.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies
- **SQL** – Data querying and analysis
- **MySQL** – Database management and query execution

## 🔍 Business Questions
1. What is the total revenue generated?
2. Which products generate the highest revenue?
3. Which product categories perform best?
4. Who are the top customers by purchase value?
5. How does revenue change over time?
6. What is the total number of orders?
7. What is the average order value?
8. Which products have the lowest sales performance?

## 📊 SQL Concepts Used
- `SELECT` and `WHERE`
- Aggregate functions: `SUM()`, `COUNT()`, `AVG()`
- `GROUP BY` and `HAVING`
- `ORDER BY`
- `JOIN` operations
- Subqueries
- Common Table Expressions (CTEs)
- Date-based analysis
